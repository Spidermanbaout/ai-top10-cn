# AI 观察站：AI Agent 排名前十

一个中文、响应式的 AI Agent 榜单页面，提供模型简介、榜单分数和官方体验入口。

## 在线预览

打开 `index.html` 即可浏览，无需安装依赖或启动构建工具。

## 榜单口径

- **来源：** [Arena 官方 Agent 榜单](https://arena.ai/leaderboard?tab=agent)，选择 **Best Overall Agents**。
- **方法：** Arena 用户匿名比较模型回答并投票；官方使用 Bradley–Terry 统计方法汇总对战结果。
- **快照：** 2026-10-08。榜单会随新投票更新，页面中的名次和分数是该日记录。
- **注意：** 这是 Agent 场景下的社区偏好榜单，不是全部 AI 产品的总排名，也不是固定题库的能力测试。前十名按官方原始条目展示，同一模型家族的不同版本和推理档位会分别占位。
- **简介：** 页面简介是便于初次了解的中文概述，不代表厂商对单项能力的保证。访问官方产品时，具体模型与套餐可用性可能因账号、地区和时间而异。

## 本地使用

直接用浏览器打开 `index.html`。项目只使用原生 HTML、CSS 和 JavaScript，没有第三方运行时依赖。
